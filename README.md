# WhatXBot

## Install firefox
sudo apt get firefox

## Create a firefox profile
Create a new profile, e.g., whatsapp-bot, and log in to WhatsApp Web manually in that profile.

Run in terminal:

firefox -P 
ls ~/.mozilla/firefox/

Look for a folder like:

abc1234.whatsapp-bot

Copy the full path, e.g.:
/home/youruser/.mozilla/firefox/abc1234.whatsapp-bot
